# Сайтты құрастыру және тексеру

Сайт — бір ғана `index.html` файлы (репозиторийдің түбінде). Оны осы қалтадағы Python скрипттері
қабат-қабат құрастырады: әр скрипт алдыңғы нәтижеге бір бөлікті қосады (дизайн, «Талдауларым»,
«Зертхана», «Фокус режимі» т.б.). Фреймворк, сервер, сыртқы кітапхана жоқ.

## Қалталар

| Қалта | Ішінде |
|---|---|
| `src/` | құрастыру скрипттері және бастапқы бет `base.html` |
| `data/` | жұмыс парақтары (`worksheets.json`), сөздік (`glossary.txt`), балалар кітаптары (`kids.json`) |
| `photos/` | сайттағы суреттер (WebP) |
| `fonts/` | Inter және Literata қаріптері (SIL Open Font License 1.1, Fontsource) |
| `tests/` | браузерде жүретін тесттер (Playwright) және `run.sh` |

## Нұсқаулықтың толық мәтіні репозиторийде жоқ

Әдістемелік нұсқаулық PDF ретінде сатылады, сондықтан оның толық мәтіні (`guide.pdf`, `guide.txt`,
`guide.json`) бұл жария репозиторийге қойылмайды (`.gitignore`). Сайтқа тек кіріспе, 1–2-бөлімдер және
қысқа кеңестер кіреді (`src/preview.py`). Құрастыру үшін `guide.json` керек — оны өз PDF-іңізден жасаңыз:

```
pdftotext -layout guide.pdf guide.txt
python3 -I tools/src/build_guide.py guide.txt guide.json
```

`guide.pdf`-ті (немесе дайын `guide.json`-ды) өзіңізде, мысалы, Google Drive-та сақтаңыз.

## Құрастыру

```
tools/build.sh /жол/guide.json            # index.html-ді қайта жасайды
tools/build.sh /жол/guide.json out.html   # басқа файлға
```

Python 3 керек. Скрипттердің кез келгенінде «anchor found 0 times» деген қате шықса, ол алдыңғы
қабаттағы мәтін өзгергенін білдіреді: сол скрипттегі `rep(...)` ізін жаңартыңыз.

## Тексеру

```
npm i -D playwright && npx playwright install chromium   # бір рет
tools/tests/run.sh                                         # index.html-ді тексереді
```

12 тест жиынтығы (400-ден астам тексеріс): Зертхананың 10 құралы, ЖИ тәлімгері, нұсқаулық, сөздік,
балалар кітаптары, сатып алу, Word/PDF сақтау, «Талдауларым», мұқаба; компьютер мен телефон өлшемдерінде.
Сайттың өз бетін (localhost) жүктеуі «сыртқы сұраныс» деп есептелмейді.

## Өзгеріс енгізу тәртібі

1. Керекті скриптті (`src/…py`) өзгертіңіз немесе тізбектің соңына жаңа скрипт қосыңыз (`build.sh`).
2. `tools/build.sh /жол/guide.json` — `index.html` жаңарады.
3. `tools/tests/run.sh` — тесттер өтуі керек.
4. `index.html` және `tools/` өзгерістерін бірге commit жасаңыз.
